## Selected work

### [Vennekredsen for Hashøjskolen](https://github.com/jfriisj/vennekredsen)

A full-stack platform supporting both a public website and internal workflows for a volunteer organization. The system includes support applications, a protected member area, inventory, purchase calculations, and administration.

**Stack:** Flask · PostgreSQL · Nginx · JavaScript

### [Co-located Multi-user VR](https://github.com/jfriisj/multi-user-vr)

An affordable multi-user VR system designed for several Meta Quest 3 users sharing the same physical space. The project explores networking, avatar synchronization, shared boundaries, collision awareness, and the challenges of co-located VR.

**Stack:** Unity · C# · Netcode for GameObjects · OpenXR / XR Interaction Toolkit

### MSc project — Real-time speech translation

Designed a scalable speech-to-multilingual translation architecture focused on **low-latency interaction (targeting 1–3 seconds end-to-end)**, AI model integration, orchestration, and system architecture.
